Cover images for concept, case and quantum films.

Name the file after the slug, as a .jpg:
  firewall.jpg       -> /dashboard/concepts/firewall
  zero-day.jpg       -> /dashboard/concepts/zero-day
  hospital.jpg       -> /dashboard/cases/hospital
  locked-chest.jpg   -> /dashboard/beyond/quantum/locked-chest
  spinning-coin.jpg  -> /dashboard/beyond/quantum/spinning-coin

One file does two jobs: the picture on the card in the listing, and the
poster the video shows before it is played.

Any size; 16:9 looks best. Drop one in and it appears with no code change.
A slug with no file falls back to its icon, so nothing ever looks broken.
